## Intent

**Problem:** Seven ledger entries owned by this last Epic 45 burn-down touch the TypeScript servers, one IRIS-side method and the docs: an install-off profile refuses after every release even when the IRIS-side classes did not change (DW-770); the startup bootstrap takes its namespace and its message host:port from `IRIS_*` while the default profile's client and tools follow an `IRIS_PROFILES` `default` entry (DW-767); `iris_sql_analyze` `stats`, `running` and `advise` show other sessions' literals under `block` (DW-784); a least-privilege account always gets `Compile failed: 35 of 35` (DW-788); the bootstrap ignores the `%Status` row of `Setup_Configure`/`Setup_ConfigureMapping`, so a refused call reports `configured: true` (DW-790); TypeScript texts describe the pre-45.6 least-privilege behavior (DW-791); and an IPM install that fails after `ConfigureMapping` created `%ALL` leaves the namespace table broken (DW-792). `SECURITY.md` carries two Planner wording fixes.

**Approach:** Probed first on throwaways (Design Notes, P-767 to P-X). Each entry gets the smallest fix the probe supports, every one ends `resolved`, `BOOTSTRAP_VERSION` moves once (DW-792's `Setup.cls` change), each behavior change carries a sanction id, and the README 45.5 section, CHANGELOG, changesets and doc pins move in the same change.
