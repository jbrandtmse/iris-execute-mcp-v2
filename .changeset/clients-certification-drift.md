feat(clients): adapter certification + doctor config-drift guard (Epic 33, Story 33.4)

**Doctor config-drift guard.** `iris-mcp-clients doctor` gains a `config-drift` finding, distinct from `parseability`: a config that PARSES but fails the adapter's root-key shape expectation (the root key present with the wrong shape, or a top level that isn't the format's object form at all) now warns with the client, path, expectation, what was found (type only, never content), and the `ADAPTER_DATA_VERSION` the expectation came from. An absent root key with other content is a normal no-MCP-section config — never drift; empty/missing files produce no finding. The drift fix is a data patch (adapter record + `ADAPTER_DATA_VERSION` bump + fixture update), never an engine change — procedure documented in the package README. `readers.ts` also exports the finer `diagnoseConfigSurface` classification the check consumes (same shared parse path as the reader — they can never disagree about what "parses").

**Adapter certification.** New `scripts/certify.mjs` harness runs one scripted certification pass per locally installed client against its REAL config — add (engine apply) → client surfaces the entry → disable → absent → remove → byte-exact verified restore with an engine-restore ladder and a loudly-reported raw-snapshot last resort; manager state, pass-created backups, and Kimi session artifacts are cleaned up every pass. Claude Code, VS Code, Cline, and Kimi Code are **certified-live** (2026-07-28); the other nine adapters carry explicit fixture-only-with-residual-risk dispositions (what the fixtures prove, what stays unproven). The README's adapter table and certification dispositions are GENERATED from `CLIENT_ADAPTERS` ⨝ `scripts/certification-results.json` by `scripts/render-certification-table.mjs` (a suite test keeps them in sync — never hand-edited).

**Certification-driven data correction (Kimi Code).** The binding spec's repo-root `.mcp.json` fallback for `kimi-code` was FALSIFIED by the live probe: kimi-code 0.29.0 loaded no project-scope server from `.mcp.json` (or from the docs-documented `.kimi-code/mcp.json`) in print mode, and the official docs document only `.kimi-code/mcp.json`. The fallback was removed from the adapter data (`ADAPTER_DATA_VERSION` 2026-07-25.2 → 2026-07-28.1): writing a config the client may never read is worse than no fallback. Repo `.mcp.json` sharing is verified for Claude Code only; Kimi Code's VS Code extension half is fixture-only-with-residual-risk (extension not installed).
